# triage-setup — この PC で、メンションの仕分けを動かす

このフォルダを受け取った人が「セットアップして」と頼むだけで、動く状態まで進めるためのスキル。
相手は、エンジニアとは限らない。黒い画面（PowerShell）にコマンドを貼り付けられる人、を想定して、ふつうの言葉で話す。

仕上がりは、次の 3 つがそろった状態。

- `python triage.py check` が、すべて `[OK]`
- 試しのメンション 1 通が、相手の専用チャンネルに届いた
- `python triage.py status` に `自動起動: 登録済み` と出る

## 先に、4 つの決まり

セットアップで触るのは、鍵と、人の Discord。ここでの失敗は、あとから取り消せない。理由と一緒に守る。

### 1. 鍵を、会話に通さない

鍵は 3 つある。ボットのトークン、Webhook の URL、Claude の合鍵。どれも、持っている人が、本人のふりをできる。
会話に出た鍵は、記録に残って消せない。だから、鍵は、相手が自分の PC のメモ帳で、鍵のファイルに直接貼る。

- 鍵を、チャットに貼るよう頼まない。
- 相手が貼ってしまったら、その鍵は使わない。「会話に残ったので、作り直してください」と伝え、作り直した鍵を、メモ帳で貼ってもらう。
- 鍵のファイル（`.env`）を、開かない・表示しない（Read、`cat`、`type`、`Get-Content` のどれも）。
  書けたかどうかは、`python triage.py check` が、鍵を出さずに教えてくれる。
- `claude setup-token` を、自分で実行しない。出てきた合鍵が、実行結果として会話に流れ込む。相手に、自分の黒い画面で打ってもらう。
- ID（ユーザー ID、チャンネル ID）は、鍵ではない。会話で受け取ってよい。

### 2. Discord に、メッセージを書き込まない。ほかの人がいるサーバーも、変えない

この仕組みの約束は「読むだけ」（[docs/security.md の「約束」](../../../docs/security.md#約束)）。セットアップの間も同じ。

- 試しのメンションも、管理者への依頼も、相手が送る。Discord に書ける道具が手元にあっても、自分では送らない。
- ほかの人がいるサーバー（会社のサーバーなど）では、設定も、チャンネルも、触らない。
- 相手自身の持ち物（自分のボット、自分だけのサーバーと、その中のチャンネル・Webhook）は、相手の Chrome で、確かめてから作ってよい。
  進め方と、そのときの決まりは、[references/collect-keys.md](references/collect-keys.md)。

### 3. PC に残る変更の前に、ひとこと確かめる

`install` は、2 分おきの自動起動を登録する（古い版が動いていれば、止めて置き換える）。`uninstall` と `init --force` も、PC に残る変更。
何が起きるかを 1 行で伝えて、「はい」をもらってから実行する。`check` と `status` は、読むだけなので、確かめなくてよい。

### 4. すでに動いている PC では、そっと見る

`自動起動: 登録済み` と出る PC では、本番が動いている。`run` は、本当に仕分けて、専用チャンネルに届ける。
様子を見るだけなら、`python triage.py run --dry-run`（何も進めず、Claude も動かさない）を使う。

## 進め方

コマンドは、このリポジトリのフォルダ（`triage.py` がある所）で実行する。自分で実行できるものは、自分で実行し、出力を読んで次を決める。
相手に頼むのは、相手にしかできないこと（鍵が出るボタンを押す、鍵を貼る、管理者に頼む、メンションを送ってもらう）だけ。頼むのは、1 回に 1 つ。
終わったら「できた」と返してもらい、`check` で確かめてから次へ進む。

### 0. いま、どこまで進んでいるかを見る

```text
python triage.py check --no-claude
```

Claude の利用枠を使わず、Discord にも何も書かない。出力で、入口を決める。

| 出力 | 入口 |
|---|---|
| `python` が動かない | 手順 1 |
| `[NG] 設定: config.json が見つからない` | はじめての PC。手順 1 から |
| ほかの `[NG]` がある | その行の下の「→」を直す。手順 4 |
| `[NG]` が無く、`自動起動: まだ登録していない` | 手順 5 から |
| `[NG]` が無く、`自動起動: 登録済み` | もう動いている。困りごとを聞いて、「動き出したあとの相談」へ |

ほかの PC ですでに動かしていて、こちらへ移すときは、先に [docs/porting.md](../../../docs/porting.md) を読む
（2 台で同時に動かすと、同じ結果が 2 通届く）。

### 1. 道具を確かめる

```text
python --version
claude --version
```

- Python は 3.10 以上。無ければ、[python.org](https://www.python.org/downloads/) から入れてもらい、黒い画面を開き直してもらう。
- `claude` が「認識されません」なら、コマンド版が入っていない（デスクトップ版だけでは入らない）。
  入れ方は [docs/setup.md](../../../docs/setup.md#claude-を入れる) の「`claude` を入れる」。入れたら、相手に、黒い画面で `claude` と打って、ブラウザで一度ログインしてもらう。

### 2. ボットと専用チャンネルを用意して、ID を集める

ここが、いちばん手間のかかる所。[references/collect-keys.md](references/collect-keys.md) を読んで、その「1 回目」を進める。

- Claude in Chrome が使えるなら、相手の Chrome で画面を開き、ボット、自分だけのサーバー、専用チャンネル、Webhook を、確かめてから作る。
  使えなければ、同じ順で、次の 1 手だけを、言葉で伝える。
- **ボットから始める。** ボットだけは、サーバーの管理者に入れてもらう必要があり、返事を待つ。先に頼んでもらい、待つ間に、残りを進める。
- 鍵 3 つ（ボットのトークン、Webhook の URL、Claude の合鍵）は、**会話には貼らない**と、はじめに伝える。鍵を出すのは、手順 4。
- すでにあるもの（ボット、専用チャンネル）は、作り直さない。あるかどうかを、先に聞く。
- ほかの人のボットのトークンを、もらって使うことを勧めない。ボットは、各自が自分で作って、管理者に入れてもらう。トークンは、作った本人の PC だけに置く
  （[ADR-0018](../../../docs/adr/0018-per-person-bot-no-shared-host.md)）。
- 「秘書（Claude）に、事実確認のために読ませてよいフォルダ」があるかも聞く（仕事のリポジトリなど。無くてよい）。

この手順で手に入るのは、相手のユーザー ID と、専用チャンネルの ID（どちらも、鍵ではない）。

### 3. 設定を作る

ID 2 つがそろったら、質問なしで、設定と、鍵を書く欄だけのファイルを作る。

```text
python triage.py init --name <名前> --user-id <ユーザー ID> --channel-id <チャンネル ID> --no-input
```

- `<名前>` は、英小文字と数字。フォルダ名になる。こだわりが無ければ、`--name` ごと省く（PC のユーザー名になる）。
- 読ませてよいフォルダがあれば、`--read-dir "<フォルダ>"` を足す。
- 「すでに設定があります」と出たら、上書きしない。`check` へ進む。作り直すのは、相手がそう望んだときだけ（`--force`。決まり 3）。

設定は、ホームフォルダの `.discord-mention-triage` にできる。リポジトリの中には、何も置かれない。

黒い画面に慣れている人は、`python triage.py init` を自分で打って、質問に答えてもよい（鍵は、貼っても画面に出ない）。
その場合は、手順 4 は、`check` だけでよい。

### 4. 鍵を書いてもらい、確かめる

[references/collect-keys.md](references/collect-keys.md) の「2 回目」を進める。`init` が最後に出す `notepad "…\.env"` の 2 行が、鍵を書くファイル。
メモ帳で開き、鍵が出るボタンを、相手に 1 つずつ押してもらって、`=` の右に貼って保存してもらう（`=` の前後に、空白や引用符を入れない）。
相手が鍵を出している間は、画面を見ない。

| ファイル | 書く行 |
|---|---|
| `.discord-mention-triage\.env` | `DISCORD_BOT_TOKEN=` の右に、鍵 ① |
| `.discord-mention-triage\<名前>\.env` | `DIGEST_WEBHOOK=` の右に、鍵 ②。`CLAUDE_CODE_OAUTH_TOKEN=` の右に、鍵 ③ |

「書けた」と返ってきたら、確かめる。

```text
python triage.py check
```

設定、ボットの鍵、Discord を読めるか、Webhook、Claude を、順に確かめる（Claude は、小さいモデルを 1 回だけ動かす）。
`[NG]` の行の下に、「→」で直し方が出る。相手に、直し方を 1 つだけ伝え、直ったら、もう一度 `check`。すべて `[OK]` になるまで繰り返す。

| よくある `[NG]` | 相手に頼むこと |
|---|---|
| `ボットのトークン: 無い`、`Webhook: 無い` | まだ貼れていない。メモ帳で、行の形（`名前=鍵`）を確かめてもらう |
| `Discord を読めない: http_401…` | ボットのトークンが違う。開発者サイトで「トークンをリセット」して、貼り直す |
| `Discord を読めない: http_403…` | ボットが、まだサーバーに入っていない、または「メッセージ履歴を読む」権限が無い。サーバーの管理者に頼む |
| `Claude: 動かなかった（claude_auth）` | 合鍵が無いか、違う。`claude setup-token` をやり直して、貼り直す |
| `Claude: 動かなかった（claude_not_found）` | 手順 1 の `claude` の入れ方へ戻る |

専用チャンネルに届くかまで見たいときは、相手に断ってから `python triage.py check --post-test`（確認用の投稿が 1 通届く）。

### 5. 手で 1 回動かして、試す

1. `python triage.py run` を 1 回。初回は「いまから見張りを始める」の合図になる（それより前のメンションは、拾わない）。
2. 相手に、同僚か別のアカウントから、自分宛てのメンションを 1 通送ってもらう。
3. 2〜3 分待つ（投稿が Discord の検索に出るまで、約 100 秒かかる）。
4. もう一度 `python triage.py run`。秘書（Claude）が動いて、専用チャンネルに結果が届く。届いたかを、相手に見てもらう。

`run` は、結果を 1 行で出す。

| 出力の中身 | 意味 |
|---|---|
| `FIRST=1` | 初回。見張りを始めた |
| `FOUND=0` | まだ検索に出ていない。1 分待って、もう一度 |
| `RAN=1 RESULT=done` | 仕分けて、届けた |
| `SKIP=reacted:1` など | 相手がもうスタンプを押した・返信した分。届けないのが正しい |
| `POLL=down:…` | Discord を読めていない。`check` へ戻る |
| `POLL=resident_watcher` | 古い版が、まだ動いている。手順 6 の `install` が置き換える |
| `SKIPPED=locked` | 自動起動のほうが、ちょうど動いている。少し待つ |

メンションを送った本人が、すぐスタンプを押すと、届かない（正常）。試すときは、押さずに待ってもらう。

### 6. 自動で動かす

「2 分おきに自動で動かす登録をします。PC が起きていて、ログオンしている間だけ動きます。よいですか」と確かめてから。

```text
python triage.py install
python triage.py status
```

`自動起動: 登録済み` と `Discord: 読めている` が出れば、終わり。

### 7. 終わりに伝えること

- メンションから届くまで、3〜6 分ほど。自分でスタンプを押した・返信した分は、届かない。
- 「対応不要」だけのときは、通知が出ない（結果は、専用チャンネルに残る）。返信の下書きか、スタンプのおすすめがあるときだけ、通知が出る。
- 様子を見たい、届かない、やめたい、というときは、同じフォルダを Claude Code で開いて、そう伝えればよい（下の「動き出したあとの相談」で受ける）。
- 専用チャンネルは、自分だけが見られる状態に保つ。結果には、メンションの引用が入り、機密を含むことがある。作ったサーバーに、人を招待しない。
- 個人の Claude の契約で動かしているなら、claude.ai の 設定 → プライバシー で、学習への利用（Help improve our AI models）を OFF にしておく。
- 「⚠」で始まる通知が届いたら、[docs/troubleshooting.md](../../../docs/troubleshooting.md) の表のとおりにする。
- 鍵を置いた場所（ホームフォルダの `.discord-mention-triage`）は、人に渡さない、リポジトリにも入れない。

## 動き出したあとの相談

セットアップが済んだあとに、「状態を見て」「届かなくなった」「通知が来た」「このフォルダも読ませて」「外したい」と言われたら、ここを使う。
相手に、コマンドを打たせない。自分で実行して、出力を読み、分かったことと、相手がすることを 1 つだけ、ふつうの言葉で伝える。

### 状態を見る・原因を調べる

```text
python triage.py status
python triage.py check
```

1. まず `status`。自動起動、Discord を読めているか、Claude を止めているか、溜まっている件数、最近の記録が出る。
2. 次に `check`。設定、鍵、Discord、Webhook、Claude を順に確かめ、`[NG]` の下に「→」で直し方が出る。
   Claude の確認は、小さいモデルを 1 回動かす。利用枠を使いたくないときは `python triage.py check --no-claude`。
3. どちらも正常なのに「届かない」と言われたら、`python triage.py run --dry-run` の `FOUND=` を見る（状態は進まず、Claude も動かない）。
   0 なら、次を伝える。届くまで 3〜6 分かかる。自分でスタンプを押した・返信した分は、届かない。ボットに見えないチャンネルと DM は、拾えない。
   PC がスリープしていた間は、止まる。

| 分かったこと | 相手に伝えること |
|---|---|
| `自動起動: 登録されていない` | 自動で動いていない。確かめてから `python triage.py install`（決まり 3） |
| `Discord: 読めていない`、`http_401…` | ボットのトークンが違う。[references/collect-keys.md](references/collect-keys.md) の F で、貼り直してもらう |
| `http_403…` | ボットのロールを、サーバーの管理者に確かめてもらう |
| `Claude: 止めている`、`claude_auth` | Claude の合鍵が切れた、または違う。同じ手順書の H で、作り直してもらう |
| `失敗で退避` が 1 件以上 | その件だけ、処理できなかった。`failed` フォルダにあること、やり直すなら `inbox` へ戻すことを伝える |

通知の意味と、記録の読み方は [docs/troubleshooting.md](../../../docs/troubleshooting.md)。

### 読ませるフォルダを変える

「このフォルダも読ませて」「このチャンネルの件は、このリポジトリで確かめて」と言われたら、ここを使う。
秘書（Claude）が事実確認のために読めるフォルダは、設定（ホームフォルダの `.discord-mention-triage\config.json`）の 2 か所で決まる。

| 項目 | 読める回 | 書き方の例 |
|---|---|---|
| `read_dirs` | どの件でも | `["C:/work/game"]` |
| `channel_read_dirs` | そのチャンネルの件が来た回だけ。ID は、フォーラムなどスレッドの親でもよく、中のスレッドにも当たる | `{"123456789012345678": ["C:/work/docs"]}` |

1. フォルダが、この PC にあるかを確かめる。無ければ、そう伝えて止める。
   読めたものは、専用チャンネルの結果に引用されうる。鍵や個人の書類が入ったフォルダ（`.discord-mention-triage` を含む）は、足さない。
2. チャンネルごとにするなら、チャンネルの ID をもらう。Discord でチャンネル（フォーラムなら、その親）を右クリック →「ID をコピー」（開発者モードが要る）。
   結果に付くリンク `https://discord.com/channels/<サーバー>/<チャンネル>/<メッセージ>` の 2 つめの数字でもよい（スレッドのリンクなら、そのスレッドだけに当たる）。ID は鍵ではないので、会話で受け取ってよい。
3. 「設定の read_dirs に C:/work/game を足します。次の回から読みます。よいですか」のように確かめてから（決まり 3）、config.json の該当する所だけを書き換える。
   ほかの項目には触らない。パスは `/` 区切りで書く（`\` は JSON では 2 つ重ねる必要があり、間違えやすい）。
4. `python triage.py check --no-claude` で `[OK] 設定` と出ることを確かめる。次の回から効く。自動起動の登録し直しは要らない。

### 外す

「2 分おきの自動起動を外します。設定と鍵は、PC に残ります。よいですか」と確かめてから、`python triage.py uninstall`（決まり 3）。
外したあとに、次を伝える。ボットは、管理者に、サーバーから外してもらう。鍵を無効にするなら、Webhook を削除し、ボットのトークンをリセットする（押すのは相手）。

### 直せないとき

分かったこと（どのコマンドが、何と出したか）を、鍵を含めずにまとめて、相手に伝える。
設定のファイルやプログラムを、その場の思いつきで書き換えて通そうとしない。このリポジトリの決まり（[CLAUDE.md](../../../CLAUDE.md) の鉄則）は、
セットアップの間も、相談の間も、変わらない。別の PC へ移すときは [docs/porting.md](../../../docs/porting.md)。
