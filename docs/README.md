## 書き方

- 1 つの話は、1 つのページにだけ書く。README には入口と要約だけを書き、詳しい所はここへリンクする。
- 結論を先に書き、読む人が使わない説明は書かない。ソフトとしての事実と理由だけを書く（[ADR-0026](adr/0026-docs-carry-only-software-reasons.md)）。
- 絵は SVG のまま `figs/` に置き、相対参照で埋め込む。背景を付けて、GitHub の明るい表示でも暗い表示でも読めるようにする。
- 鍵（トークン）や Webhook の URL、メッセージの本文は書かない。例の名前と発言は、作り物にする。
- ページを足したら、上の表に 1 行足す。
