# ADR-0017: セットアップは、リポジトリに同梱したスキルで、Claude Code に進めてもらう

## 背景と課題

- セットアップは、コマンド 1 種類・5 ステップまで短くした（[ADR-0015](0015-one-command-one-folder.md)）。それでも、README には、用意するものの表と、
  コマンドの表が残り、読む人は、`[NG]` が出るたびに、自分で直し方を読み解く必要があった。
- この仕組みを使う人は、必ず Claude Code（`claude`）を持っている（仕分けに使うため）。なら、手順を読んで進める役も、Claude に任せられる。
- umezy さんから「セットアップ全体を、スキルとしてラップする。README もすっきりするはず」と依頼があった（2026-10-10）。

## 決定

- **セットアップの手順書を、スキルとして `.claude/skills/triage-setup/` に置く。** フォルダを Claude Code で開いて「セットアップして」と頼む
  （または `/triage-setup`）と、道具の確認から自動起動の登録までを、Claude が順に進める。置き場は、リポジトリの中。フォルダと一緒に配るため。
- **スキルは、新しい仕組みを足さない。** 実行するのは、これまでと同じ `python triage.py ...`。スキルは、順番と、出力の読み方と、守ることを書いた文章。
- **鍵は、会話に通さない。** スキルは、鍵を聞かず、鍵のファイルも開かない。そのために `init` に `--no-input` を足した
  （質問をせず、設定と、空の欄だけの鍵のファイルを作る。鍵は、人が、メモ帳で貼る）。`claude setup-token` も、人が自分の画面で打つ。
- **Discord へは、書き込まない。** 試しのメンションは、人が送る。自動起動の登録など、PC に残る変更は、ひとこと確かめてから実行する。
- **README のセットアップは、3 ステップにする**（置く、頼む、答える）。用意するものの表と、コマンドの表は、`wiki/setup-guide.md` に置く。

### 結果

- 得るもの: README が、さらに短くなる。`[NG]` の読み解きと、次に何をするかを、Claude が引き受ける。
- 引き受けるもの: 手順を書く場所が、スキルと `wiki/setup-guide.md` の 2 つになる。コマンドや出力を変えたら、両方を直す
  （`tests/test_setup_skill.py` が、書いてあるコマンドと指定が実在するかを確かめる）。
- 守ること: 仕分けの Claude（`claude -p`）は、このスキルを読まない（`--disable-slash-commands`、作業フォルダもリポジトリの外。変えない）。
- まだ確かめていないこと: 何も入っていない PC で、スキルを最初から最後まで通すこと。次に配るときに確かめる。

## 採らなかった案

- スキルを、利用者のホームフォルダ（`~/.claude/skills/`）に入れてもらう: 入れる手順が 1 つ増える。リポジトリと版がずれる。
- セットアップを全部こなすスクリプトを足す: 止まる所は、人にしかできないこと（鍵を作る、メンションを送る）。対話で進めるほうが向いている。
  コマンドを増やさない決まり（ADR-0015）にも合わない。
- スキルが、鍵を会話で受け取って、ファイルに書く: いちばん手数が少ないが、鍵が会話の記録に残る。採らない。
