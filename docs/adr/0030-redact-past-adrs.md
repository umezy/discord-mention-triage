# ADR-0030: 秘密、組織の事情、ほかの人の名前は、過去の ADR からも消してよい

## 背景と課題

- 「過去の ADR は書き換えない」と、[ADR-0026](0026-docs-carry-only-software-reasons.md) の「組織の事情と、ほかの人の名前は書かない」がぶつかる。
- 公開の前に、0004（個人の環境にしか無いスキルの名前）、0008（書き手の一人称）、0012（個人の契約の経緯と、図の中の契約名）を直した。

## 決定

- **秘密、組織の事情、ほかの人の名前が入っていたら、過去の ADR からも消してよい。** 誤字やリンク切れと同じく、そのまま直す。
- 決定の中身は、これまでどおり書き換えない。変えるときは、新しい ADR を足す。

### 結果

- 得るもの: 公開してはいけないものを、いまの文書から外せる。
- 引き受けるもの: 消した箇所は、その ADR を読んでも分からない。Git の履歴には残るので、秘密は、消すだけでなく作り直す。

## 採らなかった案

- 消さずに、新しい ADR で「この記述は無効」と書く: 公開してはいけないものが、いまの文書に残り続ける。
