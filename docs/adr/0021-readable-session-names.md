# ADR-0021: セッションの名前は、送り主・用件の頭・場所から作る。通す文字は、決め打ちにする

## 背景と課題

- デスクトップ版の左側に並ぶ名前は、`triage 00:41 d29cffb3e2`（時刻と実行 ID）だった。開かないと、誰の、何の件かが分からない。
  umezy さんから、「マジックナンバーでない名前にして」と頼まれた（2026-10-10）。
- 名前は `claude -p --name` で渡すので、**Claude が動く前に決まる**。Claude が読んだ結果（返信が要るか、要点）は、入れられない。
  使えるのは、届いた件（`pending-*.json`）に書いてあることだけ。
- [ADR-0009](0009-import-sessions-into-desktop.md) は、「メンション本文は入れない」と決めていた（理由は、書いていない）。
  中身が分かる名前にするには、送り主・場所・本文のどれかを入れるしかなく、**どれも、サーバーの誰でも書ける文字列**。
- この PC で確かめた（2026-10-10）。
  - `claude` は、npm が置いた `claude.CMD`。引数は cmd.exe を通る。同じ形の `.cmd` に `"& echo X > f & "` を渡すと、ファイル `f` ができた。
    `%USERNAME%` は、ログインしているユーザー名に展開された（鍵を持つ環境変数の名前を書かれると、値が名前に入る）。
  - 日本語の名前（`「」` と `#` を含む）は、Python → `claude.CMD` → `claude.exe`（2.1.291）で、そのまま記録に入った（`custom-title`）。
  - 表示名には、空白が入る（`@taro / たろう`）。本文だけからは、「@名前」の切れ目を当てられない。

## 決定

1. **名前は `<送り主>「<用件の頭>」#<場所> ほかN件`**（例: `alice「来週の予定を教えてもらえますか」#dev ほか2件`）。
   時刻と実行 ID は、入れない（時刻は、一覧に出る。実行記録とは、`session_id` でつながる）。
2. **届いた件から、機械的に作る**（`pipeline/session_naming.py`。AI は使わない）。代表は、本人への直接のメンションの最初の件。
   用件は、宛先になった発言の頭（全角で 20 字まで）。メンション・URL・カスタム絵文字は除く。場所は、チャンネル名（スレッドなら、題）。
3. **通す文字を、決め打ちにする。** 文字・数字・空白と、`_-.、。・（）！？…〜～` だけ。ほかは、空白に置き換える。
   `「」#` は、組み立てるときにだけ足す。先頭は、`-` にしない。`build_command` は、この形でない名前を、引数に載せない。
4. 受付は、本文で名前に置き換えた相手を、件に残す（`mention_names`）。名前を作るときに、「@名前」を取り除くため。
5. 名前は、実行記録（`runs/`）にも、ログにも書かない（本文が入るため）。
6. [ADR-0009](0009-import-sessions-into-desktop.md) の「メンション本文は入れない」を、置き換える。取り込みの決定は、そのまま。

### 結果

- 得るもの: 一覧を見るだけで、誰の、何の件かが分かる。
- 引き受けるもの:
  - **本文の頭が、開かなくても一覧に見える。** 画面を共有すると、映る。機微な件（指示文の「絶対に守ること」の 5）も、機械的には見分けられないので、同じ。
    記録そのものには、もともと本文が入っている（[ADR-0008](0008-keep-session-transcripts.md)）。
  - **名前に、誰でも書ける文字列が入る。** 短く切り、記号を落としてあるが、文として読めるものは残る。一覧を読む人も、ほかの Claude も、命令として扱わない（鉄則 2）。
  - 引数に、日本語が載る。この PC では壊れなかった。ほかの入れ方で壊れたら、名前が読めなくなる（仕分けは止まらない）。
  - 絵文字と、ほとんどの記号は、名前から落ちる。古い件（`mention_names` が無い）は、`@` の直後の 1 語だけを除く。

## 採らなかった案

- **送り主と場所だけにする（本文を入れない）**: スレッドの中なら、題で見当がつく。ふつうのチャンネル（`#雑談` など）では、何の件か分からない。
  本文の頭が一覧に出るのを避けたくなったら、この形に戻す（用件の部分を外すだけ）。
- **Claude に題を付けさせる**: いちばん分かりやすい名前になる。ただし、名前は動く前にしか渡せず、あとから変える公式の方法が無い
  （記録ファイルに行を足せば変わるが、Claude Code の内部の形に頼る）。
- **危ない文字だけを除く**: 漏れが 1 つあれば、コマンドが動く。通す側を決める。
- **`claude.cmd` を避けて、`claude.exe` を直接探す**: 根は断てるが、探し方（`claude_bin.py`）を変える、別の決定になる。
  名前の側で防いでおけば、どの入れ方でも安全。
